# uruk.company

Static bilingual (Arabic / English) website for **URUK — مكتب أوروك الهندسي**,
Engineering Consultancy & General Contracting.

- `index.html`, `styles.css`, `main.js`: the whole site, with no build step.
- Contact details (phone, WhatsApp, Facebook and others) live in the `CONTACT` object at the top of `main.js`.
- `CNAME` points GitHub Pages at `uruk.company`.
